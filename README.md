# 齐天小圣 · 像素西游

一个致敬《造梦西游3》的 **2D 横版动作刷宝** 小游戏。悟空闯二十关、打妖王、升级、刷装备、炼制法宝，再入轮回。

- 纯前端、零依赖，**双击 `index.html` 就能玩**
- 六部位装备 + 特殊词条，跳过过关佛缘，让刷到的每件装备都可能改变玩法
- 三技能栏 + 五技能池，无冷却施法互斥，靠装备堆法力、靠悟道精魄突破
- 二十关二十妖王，小怪与 Boss 基础数值整体上调 50%，并随关卡继续递增
- 商店、熔炉、选关、轮回、时装五大系统；金币与轮回石双经济
- 四件法宝：玉净瓶、番天印、东皇钟、异界诛仙剑
- 机甲时装「机甲·齐天」
- 480×270 低分辨率 Canvas 放大，程序化像素美术 + WebAudio 芯片音效
- 键盘 / 触屏均可操作，自动本地存档

## 开始游戏

直接双击 `index.html`（推荐 Edge / Chrome）。

如果浏览器限制本地文件运行，也可以在项目目录执行：

```bash
python -m http.server 9123
```

然后访问 <http://127.0.0.1:9123/>。

**关卡难度递增**：小怪与 Boss 的生命、攻击、防御改为**逐关乘算成长**（小怪生命每关约 ×1.12、攻击 ×1.10；Boss 生命 ×1.10、攻击 ×1.085），并且整体数值再翻倍；实测小怪第 20 关约 **848 血 / 128 攻**，第 20 关 Boss 约 **22 万血 / 2755 攻**；轮回后继续叠加。

### 妖王通用技能与神通

每个妖王都有自己的通用技能和专属神通，Boss 血条下方会显示正在施放的技能名。

**妖王神通进阶：**

- 每个妖王原本有 2 个专属神通
- **每逢第五关（第 5 / 10 / 15 / 20 关）的妖王额外获得 1 个全新神通，上限 3 个**：
  - 第 5 关 灵感大王 → **幽冥漩涡**（吸扯玩家并在四周连环爆发）
  - 第 10 关 六耳猕猴 → **六耳回声**（扇形音波齐射）
  - 第 15 关 鼍龙 → **翻江倒海**（七道水浪 + 水牢减速）
  - 第 20 关 魔罗 → **无边长夜**（全场黑暗、连环爆发 + 追踪暗球）

**半血狂暴：**

- 所有小怪在生命低于 **50%** 时进入狂暴：**伤害 ×1.35、防御 ×0.6、前摇 ×0.72、后摇 ×0.65、移速 ×1.12**
- 妖王进入二阶段狂暴时：**伤害 ×1.2、防御 ×0.7、移速 ×1.16**，并且出手进一步加快（前摇再 ×0.75、技能间隔更短）

**妖王韧性条（血条下方的蓝色细条）：**

- 韧性存在时：受到的伤害 **×0.55**，被控制时间 **×0.3**
- 攻击会削减韧性（约为原伤害的 50%），韧性上限约 Boss 血量的 28%，更容易打空
- 破韧时：受到的伤害 **×1.22**，控制时间 **×1.6**，并且 **无法行动**，直到韧性回满
- 韧性回复约需 **4 秒**，回满后妖王立刻恢复行动；一场战斗可以多次破韧

### 战斗

- **普攻四段连招：轻击 → 中击 → 重击 → 暴击**，伤害逐段提高，暴击段必定暴击且范围更大；按住 `J` 会自动接招
- **普攻范围已加大**：四段横向判定 36 / 42 / 50 / 58，纵向判定也放宽，更容易打到移动中的敌人
- 机甲皮肤拥有独立的四段剑路动画（横斩、回斩、劈斩、旋斩）
- 二段跳附带一整圈空翻，配合更高的跳跃弧线，能上到场景中的高台
- 筋斗云闪避带无敌帧，可以穿过弹幕与妖王攻击；**冲刺 0.26 秒、期间不下坠**，水平位移更远
- 敌人攻击前有红圈 / 红线预兆；妖王拥有砸地、冲锋、召唤、骨刺弹幕、瞬移等招式
- 暴击、吸血、击退、受击硬直、屏幕震动、顿帧、低血量红屏

### 技能系统

- 固定三个技能栏，对应 `K` / `L` / `O`
- 技能池共六个：**火眼金睛、定海神针、烈焰风暴、七十二变、烈焰棍、法相金身**
- 在技能面板（`T`）点击槽位后装配技能；同一技能不会重复装配，换技能会与原槽位互换
- **技能没有冷却**；但当前技能结束前不能释放下一个技能
- 所有技能消耗法力，法力上限主要来自装备（头饰 / 衣服 / 饰品提供法力，词条也可以加法力）
- 技能特效强化：多层扩散环、粒子爆发、光束与裂地冲击，释放时屏幕闪光与震屏更明显
- 技能等级最高五重，突破消耗 **悟道精魄**；悟道精魄由妖王、精英怪和关卡通关奖励获得

| 技能 | 效果 |
| --- | --- |
| 火眼金睛 | 锁定身前最近的敌人，对目标及其附近范围施加可叠加的持续灼烧；数值已大幅提高 |
| 定海神针 | 金箍棒化作巨柱劈下，对前方大范围敌人造成大量伤害 |
| 烈焰风暴 | 化身火焰龙卷，持续灼烧周围敌人；单次伤害与范围已提高 |
| 七十二变 | 召唤分身跟随本体，分身拥有部分生命与攻击，会模仿本体释放技能 |
| 烈焰棍 | 抡起烈焰缠身的金箍棒，对周围敌人造成一次范围伤害 |
| 法相金身 | 现出法相金身：身体变大、通体金色，攻击与防御翻倍，持续 5 秒；期间**无法使用其他技能**。强化等级越高，倍率与持续时间越强 |

### 法宝与熔炉

- 按 `B` 打开法宝阁查看 / 装备 / 催动法宝；按 `G` 打开熔炉合成法宝
- 每三关妖王掉落一种专属材料：
  - 第 1～3 关 → **净瓶灵砂**
  - 第 4～6 关 → **番天印碎片**
  - 第 7～9 关 → **东皇钟碎片**
- 集齐 3 枚对应材料，再消耗法宝灵玉即可在熔炉合成法宝

| 法宝 | 合成材料 | 效果 | 属性加成（+0 基础，随强化提升） |
| --- | --- | --- | --- |
| 玉净瓶 | 净瓶灵砂×3 + 法宝灵玉×2 | 清除灼烧、中毒、迟缓，8 秒持续回血回蓝 | 生命 +2%、冷却缩减 +1% |
| 番天印 | 番天印碎片×3 + 法宝灵玉×3 | 镇压周围敌人 2.5 秒并造成伤害 | 攻击 +3%、防御 +2% |
| 东皇钟 | 东皇钟碎片×3 + 法宝灵玉×4 | 冻结周围敌人 3.5 秒 | 攻击 +4%、生命 +4%、冷却缩减 +2% |
| 诛仙剑 | 诛仙剑魄×3 + 法宝灵玉×5 | 异界剑阵，对周围大范围敌人造成巨额伤害 | 攻击 +6%、技能增伤 +4%、暴击 +2% |
| 昆仑镜 | 轮回石×15（轮回商店） | 冻结敌人 3 秒 | **攻击 +9%、生命 +9%、防御 +7%、技能增伤 +5%、冷却缩减 +3%** |

- 法宝属性全部为 **百分比加成**，越靠后的法宝数值越高，**轮回系昆仑镜明显强于普通法宝**
- 每个法宝的 `levelStats` 会在强化时继续叠加，越强化越强

- **诛仙剑魄**是异界法宝材料，只能在轮回商店用轮回石兑换
- **每个法宝都有独立模型**，装备后会悬浮跟随在角色身后
- **法宝可以强化**：在法宝阁选中法宝后，消耗该法宝的专属材料与金币提升等级
  - 强化提升效果（伤害、控制时间、回复量、范围）
  - 昆仑镜的百分比加成也会随强化等级提高
  - 最高 +10，等级越高消耗越多
- 法宝冷却与状态会显示在 HUD 左侧
- 番天印定身只持续 **2.5 秒**，结束后敌人会立即恢复行动（已修复永久僵直）
- 负面效果包括 **灼烧**、**中毒**（持续掉血）与 **迟缓**（降低移动速度）

### 商店系统

- 按 `P` 打开云游商店，分为 **金币商店 / 轮回商店 / 时装 / 称号**
- 金币商店会根据已解锁关卡出现：
  - **强化石**、**悟道精魄**、**法宝灵玉**、**灵药**
  - 当前阶段解锁的妖王特殊材料
  - 随进度提升品质的随机装备
- 装备强化现在需要 **金币 + 强化石**；强化石可在商店购买
- 刷新商品消耗金币，进度越深刷新越贵
- 轮回商店可以用轮回石兑换：
  - **1 轮回石 = 1000 金币**
  - **诛仙剑魄**（异界法宝材料）
  - **法宝灵玉**
  - **昆仑镜**（异界法宝）
  - **机甲·齐天** 时装
- 轮回石购买的所有称号/法宝只提供 **百分比属性**，不会增加任何整数固定数值

### 选关系统

- 按 `M` 打开选关，已解锁的关卡可以随时重游
- 关卡进度、最高解锁关卡会写入存档
- 重游保留当前等级、装备、技能、法宝、时装与货币

### 灵药淬体

- 按 `V` 或暂停菜单「灵药淬体」打开
- **灵药**来源：小怪掉落（约 7.5%）、妖王奖励、商店用金币购买
- 消耗灵药淬炼肉身，**永久提升固定属性**：
  - 气血每级 +35
  - 攻击每级 +4
  - 防御每级 +3
- 等级越高单级消耗灵药越多，支持 +1 / +5 快捷淬体

### 翅膀系统

- 按 `Y` 或暂停菜单「翅膀」打开
- **每三关妖王掉落一枚对应翅膀材料**，一枚材料即可制作翅膀
- 七阶翅膀：**雏翼 → 浴火 → 核力制动 → 神光 → 星宇 → 太虚 → 无极**
- 翅膀提供 **水平速度** 与 **跳跃速度**，以及部分百分比属性；越靠后的翅膀越强
- 翅膀可消耗对应材料与金币强化（最高 +10），材料由对应关段的妖王反复产出
- 装备后会以大型羽翼跟随显示，**七阶翅膀各有独立造型与特效**：
  - 雏翼：小巧圆润的幼羽与微光
  - 浴火：火舌状羽翼，带上升火星
  - 核力制动：机械翼板与喷射推进器
  - 神光：巨大天使羽翼与放射圣光
  - 星宇：星空翼膜，翼内嵌星尘
  - 太虚：半透明虚影羽翼与符环
  - 无极：双层金翼与曼陀罗光环

### 觉醒前世

- 按 `N` 或暂停菜单「觉醒前世」打开
- 消耗轮回石永久强化百分比属性：**1 轮回石 = 1%**
- 可强化：攻击、生命、防御、技能增伤，支持 +1% / +5% 快捷强化
- 觉醒效果**永久保留**，轮回之后也不会清空

### 轮回系统

- 二十关通关后可以选择 **轮回结算** 或 **留在本轮回**
- 暂停菜单也可以随时打开轮回台
- 轮回奖励根据 **当前战力、轮回次数与已解锁关卡** 计算轮回石
- **轮回会清空当前等级、全部装备、背包、金币与悟道精魄，并重置全部技能等级与技能栏**
- 金币按 **10000 金币 = 1 轮回石**、悟道精魄按 **10 精魄 = 1 轮回石** 自动折算，与战力结算一起发放
- 称号、时装、法宝与法宝等级、材料、关卡解锁会保留
- 轮回后敌人难度提升；轮回石可用于商店兑换金币、异界法宝材料、称号与时装

### 时装系统

- 当前时装：**机甲·齐天**
- 商店「时装」页购买：第一件 **8 枚轮回石**，之后可 **3 枚/件**继续购买同款
- 时装和装备一样可自由 **穿戴 / 卸下**，卸下后回到齐天本相
- 每件时装都提供 **百分比属性**（机甲·齐天：攻击 +2%、生命 +2%）
- **三件同等级时装可合成一件更高级时装**，类似装备强化：
  - 3 × 机甲 +0 → 1 × 机甲 +1
  - 每升一级额外 +1.5% 攻击与生命
  - 最高 +5
- 背包页可查看时装等级、卸下或跳转更换
- 机甲皮肤参考蓝白机甲剑士：蓝色装甲、白色胸甲、金色饰边、红色点缀、双角头盔、青色面罩与大型光剑
- 奔跑带膝部弯曲、脚底喷焰与速度线
- 背包角色预览、分身与残影都会同步时装外观

### 称号系统

- 商店「称号」页可用轮回石购买并佩戴
- 所有称号只提供 **百分比属性**，没有固定整数加成
- 佩戴的称号会以 **放大＋金边名牌** 显示在人物头顶，并在背包界面展示，均使用清晰无衬线字体

| 轮回行者 | 3 轮回石 | 攻击 +3%、生命 +3% |
| 斩仙者 | 6 轮回石 | 攻击 +6.5%、暴击 +2.5% |
| 九界之主 | 12 轮回石 | 攻击 +8%、生命 +8%、防御 +5%、技能增伤 +3.5% |

| 万妖之王 | 累计击杀 1500 只妖怪 | 攻击 +9%、生命 +9%、降妖增伤 +4% |

### 数值平衡

- 裸装基础生命、攻击、防御整体提高，低等级也能正常清怪
- 装备主属性、随机词条、品质倍率与强化收益整体压缩
- 防御减伤曲线放缓，避免高防御后几乎不掉血
- 旧存档装备会自动进行一次兼容压缩，不会因版本更新突然失效
- 目标手感：裸装能打，穿齐装备明显变强，但不会无脑碾压
- **吸血词条数值整体减半**（生成数值与旧存档装备都会生效，旧装备自动迁移一次），吸血上限 50%

### 外观与称号

- 原皮重做为冷峻凶相：金瞳、怒眉、无高光、面部战纹
- 机甲皮肤重做为蓝白机甲骑士，奔跑带推进火焰与速度线
- 佩戴的称号会显示在角色头顶
- 背包页可查看当前皮肤与称号
- 场景横幅、波次提示等文字改用无衬线字体，提升可读性

### 六部位装备与特殊词条

- 击杀妖怪获得经验与金币，升级后气血法力回满
- **五档品质**：凡品 → 灵品 → 仙品 → 神品 → 传说
- 六个装备部位：**头饰 / 衣服 / 护腿 / 鞋子 / 武器 / 饰品**
- 特殊词条直接落在装备上：攻击加成、生命加成、防御加成、技能增伤、降妖增伤、冷却缩减、伤害减免、攻击速度、掉落品质、吸血等
- 妖王装备至少带一条特殊词条；金色词条会直接影响战斗数值
- 掉落自动拾取；更强装备会自动穿戴，也可进背包手动比较
- **背包 96 格、每页 12 件**，可用「上一页 / 下一页」翻页，新入袋会自动跳到所在页
- **怪物爆率下调**：普通怪装备掉率约 ×0.55，精英怪 0.72，生命 / 法力 / 丹药掉落同步降低；妖王奖励不受影响
- **等级无上限**：经验足够就会持续升级，属性随等级线性成长
- **法力不再匮乏**：基础法力随等级成长，头饰 / 衣服 / 饰品的法力数值上调（30 级裸装约 123 蓝，穿齐三件约 640 蓝）
- 装备可强化至 **+9**，每次强化消耗金币与 1 枚 **强化石**；也可以分解换金币
- 「分解低战力」可一次清掉所有低于同部位已装备战力的背包装备
- 删除过关佛缘系统：过关后直接进入下一关，成长全部来自等级与装备
- **装备会改变悟空外观**：头饰、衣服、护腿、鞋子、武器和饰品会在角色身上显示对应品质颜色的头盔、胸甲、肩甲、腿甲、战靴与武器光效；本体也重做为更宽厚的英雄体型与鬃毛，背包角色预览同步显示

### 存档

- 自动保存等级、经验、金币、六部位装备、背包、技能栏、技能等级、悟道精魄、法宝与法宝等级、法宝材料、强化石、轮回石、时装库存与等级、称号、觉醒前世强化、灵药与淬体等级、翅膀与翅膀等级、关卡解锁与声音设置
- 存档在浏览器 `localStorage` 中，键名 `qitian-xiaosheng-save-v1`

- 关闭页面 / 刷新后，标题页会出现「继续旅程」

## 技术说明

- 使用原生 HTML / CSS / JavaScript，无构建步骤、无外部素材和依赖
- 主画面为 480×270 逻辑分辨率，关闭平滑后由 CSS 放大，保证像素边缘
- 角色、场景、UI 图标均由 Canvas 绘制；音效与循环 BGM 由 WebAudio 实时合成
- 游戏画面在 Canvas，菜单和 HUD 使用 DOM，文本更清晰、按钮可点击
- 支持横屏触屏设备；桌面端体验最佳

这是一个非官方同人练习作，角色与西游题材来自公共文化；代码、程序化像素画面与音频均为本项目原创实现，未使用《造梦西游3》的美术或音频素材。

当前版本聚焦「打怪 → 升级 → 掉装备 → 变强 → 再战」的核心循环。后续可以继续扩展：更多角色与技能树、更多关卡与妖王、套装效果、随机事件、手柄支持、图鉴与成就系统等。
